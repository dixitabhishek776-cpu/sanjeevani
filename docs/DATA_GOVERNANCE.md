# Sanjeevani Data Governance

## Data classes
- Account identifiers: email, display name, role.
- Sensitive wellbeing content: chats, journals, mood notes, safety assessments.
- Security data: password hashes, refresh-token hashes, audit events.
- Optional data: memories, voice/emotion features, wearables and research participation.

## Principles
- Collect only what is necessary.
- Default optional processing to off.
- Record consent separately and version it.
- Encrypt sensitive content at rest.
- Restrict reviewer access by role and audit it.
- Provide export and deletion controls.
- Define and automate retention/deletion policies where permitted or required.
- Never use private conversations for model training without a separate explicit informed opt-in and governance review.

India's DPDP Rules 2025 require clear notices and security safeguards; exact launch-date obligations must be checked with counsel.
